# ADS(アシッドデモンストレーション)は念鎧で軽減できるか — 調査メモ 2026-11-18

## 結論(先に)
**決められない。「実測なし・推測」。** 念鎧で約1/4になる可能性は高いが、統制した実測はまだ無い。
ラトリオでは4条件の実測はできなかった(理由は下)。

## 1. ADSを使う敵と出現マップ(`被ダメ記録.json` の stats より。ana.txt / ana2.txt は見つからず、これで代替)
行の形 = [回数, 合計, 最大(1回=1パケットの合計), 時刻, 総hit数, 近接計, 遠距離計, 最新]。**この「最大」は1回の使用の合計**(le100 の 4,414,120 は10hit合計 → 1hit約441,412)。

| **無口なマヤー** | **MD le100** | Fox_Fourteen | 1 | **4,414,120**(10hit) | 2026-10-26 08:18。**このとき装備の一覧が届いておらず(動作ログ 07:51 「12秒たっても…」)、鎧は不明** |
| 無口なマヤー | Labyrinth of Phantom P(動作ログでは該当時刻に le100 内。同じMDの別名の可能性が高い・台帳では未確認) | Fox_Seven | 5 | 1,005,460(10hit) | 念鎧(無耐性15) |

- 候補のうち le100 の 4,414,120 は **無口なマヤー(ADS)** で確定。ただしラトリオ上の ID(1441 通常 / 1716 MD版)は**未確認**。
- stats の [5]/[6] は距離の分類(近接・遠距離)で、**Atk部分/Matk部分の内訳ではない**。→ 内訳は記録からは分離不可。

## 2. ラトリオでの検証環境
- `engine/battle/received-damage.js` に ADS 専用の式は無い(「モンスターの攻撃+属性を入力」する汎用)。
- 無属性と入れて念鎧で減らしても、それは計算機の前提を写しただけで**実測にならない**ので回さなかった。
- Vit0 で Miss になる仕様、無属性耐性装備の効き、Atk/Matk の分離も、ゲーム内でしか測れない。**すべて実測なし。**

## 4. 次に測れば決まること
同じキャラ・同じ階・同じ敵で、**鎧だけ替えて**各5回以上受ける: (a)鎧なし (b)念鎧 (c)無属性耐性のみ (d)念鎧+無属性耐性。
`被ダメ記録.json` の recent(300件)か stats から、回数・平均・最大を取り直す。Vit0 の Miss は別に1回確認。

## 5. 補足
- ラトリオの属性表(`engine/data/element-affinity.dat.js`): 無属性の攻撃は 念Lv1 に -75(=25%)、毒Lv1 に 0(=100%)。**ADSがこの表を通るなら予測は×0.25。これは計算機の仮定で実測ではない。**
- 倍率の精度: タッシ念鎧3回は 56,690 / 67,836 / 72,362(約±12%)。3.95倍・4.9倍は「約1/4」と矛盾しないが、倍率を確定できる精度ではない。
- 耐性の交絡: エミュールの組は念鎧のほうが地・風・毒・聖・念の耐性が低く、差は耐性では説明しにくい。タッシの組は毒耐性が20→105と同時に変わっている。
- マヤーのクラスID(1441/1716)は未確認(記録が文字化けして引けず)。ana.txt / ana2.txt は F:\Claude と Desktop では見つからず。
- 未実施: ラトリオでの4条件環境・Vit0のMiss・無属性耐性の効き・Atk/Matkの分離。
